## v1.0 — 2026-05-02 — 初始建立面试题归类

### 涉及文件
- `面试题归类.md`（新建）

### 本次新增的内容

#### 1. 整体框架
- 建立了"基于 城市生活 项目"的题目归类体系
- 明确了**仅限 城市生活 项目**作为评估范围（不结合其他项目/实习经历）
- 引入四种状态标记：
  - ✅ 项目代码能直接支撑回答
  - 🧠 项目无对应实现，纯八股可答
  - ⚠️ 可以答但有薄弱点
  - ❌ 项目完全无法支撑

#### 2. 城市生活 技术清单（用于判定）
明确列出项目实际拥有的关键技术，避免误判：
- Redis：standalone 单机（**非集群、非主从**）
- 缓存：Caffeine + Redis 二级缓存、布隆过滤器、逻辑过期+空值缓存
- 限流：自研 ZSet 滑动窗口（@SlidingWindowLimit AOP）
- 锁：Redisson、SimpleRedisLock + Lua
- 秒杀：Lua + RocketMQ 异步下单
- MQ：仅 RocketMQ（含延迟消息），**无 Kafka/RabbitMQ**
- AI：单 Agent ReAct + Spring AI + Milvus + MCP + SSE
- 数据库：MySQL（**无 ES、无分库分表、无 binlog 监听**）

#### 3. Java 方向题目归类（共 40 题）
- **缓存与一致性**（11 题）：含两级缓存一致性、缓存三件套、MQ 重试积压等
- **布隆过滤器**（6 题）：底层、删除、Counting Bloom Filter
- **秒杀**（8 题）：Lua、超卖、库存同步、流量爆炸重构
- **消息队列**（5 题）：RocketMQ 流程、Redis MQ 对比、压测数据
- **Redis 集群与分布式锁**（5 题）：哨兵、看门狗
- **基础八股**（5 题）：ThreadLocal、GEO、主键

#### 4. AI/Agent 方向题目归类（共 24 题）
- **RAG 基础**（7 题）：含字节面试 8 题精华
- **对话记忆与上下文**（4 题）
- **Prompt 与系统优化**（2 题）
- **流式输出与延迟**（3 题）
- **模型选型**（1 题）
- **Agent 工具调用与 MCP**（5 题）
- **Bad case 与幻觉**（1 题）

#### 5. 城市生活 无法解决的题目（22 题）

#### 6. 短板 / 薄弱点小结
